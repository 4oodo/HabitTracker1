🚀 КАК ЗАПУСТИТЬ

Минимум за 5 минут:

1️⃣  Создать базу данных
	• Откройте Database/CreateDatabase.sql
	• Выполните в SQL Server Management Studio

2️⃣  Запустить приложение
	• Откройте HabitTracker1.slnx в Visual Studio
	• Нажмите F5

3️⃣  Тестировать
	• Создайте новый аккаунт
	• Добавьте привычку
	• Отметьте выполнение
	• Посмотрите статистику

   • Daily (ежедневно)
   • Weekdays (по будням)
   • Weekly (еженедельно)
   • EveryNDays (каждые N дней)
   • SpecificDays (определенные дни)

2️⃣  Поддержка единиц измерения
   • Можно отслеживать количество (минуты, км, страницы)
   • Целевые значения для привычек
   • Опциональные заметки

3️⃣  Расчёт серий (streaks)
   • Текущая серия выполнения
   • Самая длинная серия (рекорд)
   • Мотивационный элемент

4️⃣  Статистика по периодам
   • День, неделя, месяц, год
   • Процент успеха
   • Тренды и анализ
