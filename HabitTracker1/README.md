# Habit Tracker - Приложение для отслеживания привычек

## Описание
Habit Tracker - это десктопное WPF приложение для создания, управления и отслеживания ежедневных привычек. Приложение позволяет пользователям следить за своим прогрессом, видеть статистику выполнения и анализировать свои достижения.

## Возможности
- ✅ Регистрация и вход в аккаунт
- ✅ Создание, редактирование и удаление привычек
- ✅ Управление категориями привычек
- ✅ Логирование выполнения привычек с опциональными значениями
- ✅ Статистика по привычкам (процент успеха, серии, тренды)
- ✅ Графики и визуализация прогресса
- ✅ Интуитивный интерфейс
- ✅ Безопасное хранение паролей (SHA256 хеширование)

## Требования к системе
- Windows 7 или выше
- .NET Framework 4.7.2
- Microsoft SQL Server (LocalDB или полноценный сервер)

## Установка и настройка

### 1. Подготовка базы данных

#### Вариант 1: Использование SQL Server Management Studio
1. Откройте SQL Server Management Studio
2. Подключитесь к серверу `DESKTOP-N513RVN`
3. Убедитесь, что база данных `HabitTrackerDb1` существует
4. Откройте файл `Database\CreateDatabase.sql`
5. Выполните скрипт для создания таблиц (Ctrl+E)

#### Вариант 2: Использование командной строки
```cmd
sqlcmd -S DESKTOP-N513RVN -d HabitTrackerDb1 -i Database\CreateDatabase.sql
```

### 2. Запуск приложения
1. Откройте решение `HabitTracker1.slnx` в Visual Studio
2. Соберите проект (Ctrl+Shift+B)
3. Запустите приложение (F5)

## Использование

### Создание аккаунта
1. На экране входа нажмите "Создать аккаунт"
2. Введите имя пользователя (минимум 3 символа)
3. Введите пароль (минимум 6 символов)
4. Подтвердите пароль
5. Введите email (опционально)
6. Нажмите "Зарегистрироваться"

### Создание привычки
1. После входа в аккаунт перейдите на страницу "Мои привычки"
2. Нажмите "+ Добавить привычку"
3. Заполните форму:
   - **Название**: описание привычки (например, "Утренняя зарядка")
   - **Категория**: выберите категорию или создайте новую
   - **Частота**: ежедневно, по будням, раз в неделю
   - **Единица измерения**: опционально (минуты, км, страницы и т.д.)
   - **Целевое значение**: опционально (например, 30 минут)
   - **Время напоминания**: опционально (HH:mm формат)
4. Нажмите "Создать"

### Логирование выполнения
1. На странице "Мои привычки" найдите нужную привычку
2. Нажмите "Отметить" чтобы отметить выполнение на сегодня
3. Для логирования за другую дату используйте опцию "История"

### Просмотр статистики
1. Перейдите на страницу "Статистика"
2. Выберите период (день, неделя, месяц, год)
3. Просмотрите процент успеха и текущую серию для каждой привычки

### Управление категориями
1. На странице "Категории" нажмите "+ Добавить категорию"
2. Введите название категории
3. Нажмите "OK"

## Архитектура проекта

### Структура папок
```
HabitTracker1/
├── Models/                    # Модели данных
│   ├── User.cs              # Модель пользователя
│   ├── Habit.cs             # Модель привычки
│   ├── Category.cs          # Модель категории
│   └── HabitLog.cs          # Модель логов выполнения
├── Views/                     # WPF страницы и окна
│   ├── LoginWindow.xaml     # Окно входа
│   ├── HabitsPage.xaml      # Страница управления привычками
│   ├── StatisticsPage.xaml  # Страница статистики
│   └── ...
├── ViewModels/               # ViewModel классы
│   ├── LoginViewModel.cs
│   ├── HabitViewModel.cs
│   └── ...
├── Services/                 # Бизнес-логика
│   ├── AuthenticationService.cs    # Аутентификация
│   ├── HabitService.cs            # Управление привычками
│   ├── CategoryService.cs         # Управление категориями
│   ├── StatisticsService.cs       # Расчет статистики
│   └── ...
├── Data/                      # Слой доступа к данным
│   └── DatabaseConnection.cs  # Подключение к БД
└── Database/
	└── CreateDatabase.sql    # SQL скрипт создания БД
```

### Паттерны проектирования
- **MVVM** (Model-View-ViewModel) для архитектуры UI
- **Service Layer** для бизнес-логики
- **Repository Pattern** через DatabaseConnection для доступа к данным

## Безопасность
- Пароли хранятся в виде SHA256 хеша
- Используется интегрированная безопасность SQL Server
- Все входные данные обрабатываются для предотвращения SQL-инъекций

## Известные ограничения
- Максимум 7 дней для логирования задним числом
- Требуется прямое подключение к SQL Server (не поддерживается Azure SQL)

## Решение проблем

### Ошибка подключения к БД
- Убедитесь, что SQL Server запущен
- Проверьте, что сервер доступен: `DESKTOP-N513RVN`
- Проверьте, что база данных `HabitTrackerDb1` существует
- Выполните скрипт `CreateDatabase.sql` для создания таблиц

### Ошибка аутентификации
- Проверьте правильность имени пользователя и пароля
- Убедитесь, что аккаунт существует в БД
