## ✨ Что было создано

### 1. **Полнофункциональное WPF приложение** для Windows

Приложение позволяет пользователям:
- Создавать и управлять привычками
- Отслеживать прогресс выполнения
- Просматривать статистику и графики
- Организовывать привычки по категориям

### 2. **Архитектура** (MVVM + Service Layer)

**Преимущества:**
- Чистая архитектура, легко расширяемая
- Разделение ответственности между слоями
- Простота тестирования кода

**Компоненты:**
```
UI Layer (Views + ViewModels)
	↓
Business Logic (Services)
	↓
Data Layer (DatabaseConnection)
	↓
SQL Server Database
```

### 3. **Основные функции**

#### Аутентификация
- ✅ Регистрация новых пользователей
- ✅ Вход в систему
- ✅ SHA256 хеширование паролей
- ✅ Безопасное управление сессией

#### Управление привычками
- ✅ Создание привычек с указанием:
  - Названия и описания
  - Категории
  - Частоты выполнения (ежедневно, по будням, еженедельно)
  - Единицы измерения (минуты, км, страницы и т.д.)
  - Целевого значения
  - Времени напоминания

#### Логирование выполнения
- ✅ Отметка привычек на сегодня
- ✅ Отметка за прошлые дни (до 7 дней назад)
- ✅ Ввод количественных значений (для привычек с единицами)
- ✅ Добавление заметок

#### Статистика
- ✅ Процент успеха за период
- ✅ Текущая серия выполнений
- ✅ Самая длинная серия (longest streak)
- ✅ Расчет по периодам (день, неделя, месяц, год)
- ✅ Статистика по категориям

#### Категоризация
- ✅ Создание пользовательских категорий
- ✅ Автоматическая привязка привычек к категориям
- ✅ Перемещение привычек между категориями
- ✅ Удаление категорий с перераспределением привычек

- `LoginWindow.xaml` - Окно входа

#### Слой данных

- `CreateDatabase.sql` - Скрипт создания структуры БД с индексами

## 💡 Интересные особенности реализации

### 1. Гибкая система частоты
Привычки поддерживают 5 типов частоты:
- Ежедневно (Daily)
- По будням (Weekdays)
- Определенные дни (SpecificDays)
- Каждые N дней (EveryNDays)
- Еженедельно (Weekly)

### 2. Единицы измерения
Можно отслеживать не только выполнение ("да/нет"), но и количество:
- Минуты (зарядка)
- Километры (бег)
- Страницы (чтение)
- Любые пользовательские единицы

### 3. Расчет серий (streaks)
- Текущая серия - сколько дней подряд выполняется привычка
- Самая длинная серия - рекорд пользователя
- Используется для мотивации

### 4. Окно ввода
Универсальное диалоговое окно InputDialogWindow для разных операций ввода
