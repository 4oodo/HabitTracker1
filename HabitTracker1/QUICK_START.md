# ⚡ Habit Tracker - Быстрый старт

## 🚀 За 5 минут до первого запуска

### Шаг 1️⃣: Подготовка базы данных (2 минуты)

#### Для Windows + SQL Server Management Studio
```
1. Откройте SQL Server Management Studio
2. Подключитесь к серверу: DESKTOP-N513RVN
3. Откройте файл: HabitTracker1/Database/CreateDatabase.sql
4. Нажмите Ctrl+E или кнопку Execute
5. ✅ База готова!
```

#### Для Windows + Command Line
```cmd
sqlcmd -S DESKTOP-N513RVN -d HabitTrackerDb1 -i Database\CreateDatabase.sql
```

#### Для Linux/Mac
```bash
sqlcmd -S DESKTOP-N513RVN -d HabitTrackerDb1 -i Database/CreateDatabase.sql
```

---

### Шаг 2️⃣: Запуск приложения (1 минута)

```
1. Откройте файл HabitTracker1.slnx в Visual Studio
2. Нажмите F5 (или Debug → Start Debugging)
3. Дождитесь загрузки приложения
4. ✅ Приложение запущено!
```

---

### Шаг 3️⃣: Первый тест (2 минуты)

#### Создание аккаунта
```
1. Нажмите кнопку "Создать аккаунт" на экране входа
2. Введите данные:
   - Имя: testuser
   - Пароль: Test12345!
   - Email: test@example.com (опционально)
3. Нажмите "Зарегистрироваться"
4. ✅ Аккаунт создан!
```

#### Добавление привычки
```
1. Перейдите на страницу "Мои привычки"
2. Нажмите "+ Добавить привычку"
3. Заполните форму:
   - Название: "Утренняя зарядка"
   - Категория: создайте новую или выберите существующую
   - Частота: Ежедневно
   - Единица: минуты
   - Целевое значение: 30
4. Нажмите "Создать"
5. ✅ Привычка добавлена!
```

#### Логирование выполнения
```
1. На странице "Мои привычки" найдите созданную привычку
2. Нажмите на неё или используйте контекстное меню
3. Отметьте выполнение на сегодня
4. ✅ Выполнение записано!
```

## 🔧 Если что-то не работает

### Ошибка: "Cannot open database 'HabitTrackerDb1'"
```
Решение:
1. Проверьте, что база данных существует в SQL Server
2. Убедитесь, что вы выполнили SQL скрипт
3. Проверьте имя сервера (должно быть DESKTOP-N513RVN)
```

### Ошибка: "Cannot connect to server"
```
Решение:
1. Убедитесь, что SQL Server запущен
2. Проверьте, что сервер доступен (пингуйте его)
3. Проверьте наличие прав на базу данных
```

### Приложение не запускается
```
Решение:
1. Проверьте, что .NET Framework 4.7.2 установлен
2. Пересоберите проект (Ctrl+Shift+B)
3. Очистите временные файлы (bin, obj)
```
