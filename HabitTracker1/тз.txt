-Практическая работа

Вам необходимо создать десктопное приложение «Habit Tracker» по отслеживанию привычек с использованием C, WPF, .NET и MS SQL.

Программа должна уметь:
- открываться и функционировать в полноэкранном режиме;
- создавать и удалять аккаунт пользователя;
- знать имя пользователя;
- создавать «привычку» (название, категория, желаемая частота, напоминание);
- иметь статистику выполнения привычек (процент успеха, непрерывная серия);
- иметь различные категории привычек (спорт, учёба, здоровье, творчество и т.д.);
- иметь возможность добавлять и удалять категории;
- иметь возможность выводить данные в виде графика (линейный график прогресса или круговая диаграмма выполнения за месяц);
- просмотр выполнения привычек по периодам (за день, неделю, месяц, любой период);
- выбор единицы измерения привычки (разы, минуты, километры, страницы и т.п.);
- просмотр каждой отдельной категории с её привычками и статистикой;
- возможность создавать напоминание о необходимости отметить выполнение привычки (например, ежедневно в 20:00).




Техническое задание: Десктопное приложение для трекера привычек

Введение

Название проекта (пример): HabitFlow

Описание:  
HabitFlow — это десктопное приложение, предназначенное для формирования и отслеживания полезных привычек. Приложение помогает пользователям регулярно выполнять запланированные действия, анализировать свой прогресс и не срываться благодаря системе напоминаний и визуальной статистике.

Основные функции приложения:
- Учёт выполнения привычек: пользователи могут отмечать выполнение привычек каждый день (или с заданной периодичностью), просматривать историю.
- Управление привычками: создание, редактирование, удаление привычек; установка желаемой частоты (ежедневно, по будням, раз в неделю, в конкретные дни).
- Анализ прогресса: различные отчёты и графики (процент успеха за период, самая сильная серия «стрик», прогноз на следующую неделю).
- Категории и теги: группировка привычек по сферам жизни для удобного анализа.
- Система мотивации: уведомления о необходимости выполнить привычку, поздравления с достижением новых рекордов.



Преимущества приложения:
- Интуитивно понятный интерфейс с визуальными индикаторами прогресса (тепловая карта недели/месяца).
- Возможность вести трекинг для нескольких пользователей (разные аккаунты на одном ПК).
- Экспорт отчётов о прогрессе для самоанализа или шеринга с коучем.
- Помощь в формировании устойчивых привычек на основе научно подтверждённого метода «не прерывай цепочку».

Основные требования

- Учёт выполнения привычек (отметка «сделано» / «пропущено» с датой).
- Возможность добавления категорий привычек.
- Процесс отслеживания и анализа регулярности выполнения.
- Генерация отчётов и статистики за определённый период (неделя, месяц, квартал).

Технические требования

- Операционная система: Windows.
- Язык программирования: C#.
- Фреймворк для UI: WPF (.NET).
- База данных: MS SQL (LocalDB или полноценный сервер).
- Дизайн приложения: современный минимализм, поддержка тёмной и светлой темы (по желанию).
- Безопасность: хранение и запись данных в БД происходит в зашифрованном виде (например, шифрование пароля пользователя и чувствительных полей).

Функциональные требования

1. Аутентификация и авторизация
- Вход в систему с помощью учётной записи пользователя (логин/пароль).
- Создание нового аккаунта (имя пользователя, пароль, email для восстановления – опционально).
- Возможность удалить свой аккаунт (каскадное удаление всех привычек и историй).
- Восстановление пароля (через секретный вопрос или email).

2. Управление привычками
- Добавление, изменение и удаление привычки. Поля:
- Название (например, «Утренняя зарядка»)
- Категория (выбор из существующих или создание новой)
- Желаемая частота: (ежедневно, по определённым дням недели, раз в N дней)
- Единица измерения: (разы, минуты, километры, страницы и т.п.) – опционально.
- Целевое значение (например, 30 минут, 10 000 шагов) – опционально.
- Время напоминания (можно отключить).
- Возможность отметить выполнение привычки за текущий день (с вводом количественного значения, если задано).
- Отметка за прошедшие дни (задним числом, только в пределах последних 7 дней, чтобы не читерить).

3. Категоризация
- Возможность добавлять, редактировать и удалять категории    привычек (по умолчанию: «Спорт», «Учёба», «Здоровье», «Дом», «Работа», «Саморазвитие»).
- При удалении категории привычки, относившиеся к ней, переходят в категорию «Без категории» (либо пользователь подтверждает перепривязку).

4. Генерация отчетов и статистики
- Возможность создавать отчёт о выполнении привычек за произвольный период (день, неделя, месяц, 3 месяца, год).
- Отображение статистики по категориям: какая категория имеет наибольший процент выполнения.
- Процент успеха за период: (кол-во выполненных отметок) / (кол-во ожидаемых выполнений согласно частоте) * 100%.
- Самый длинный непрерывный стрик (daily streak) для каждой привычки.
- Тепловая карта выполнения за месяц (квадратики с цветом в зависимости от факта выполнения).

5. Графики
- Возможность выводить данные в виде линейного графика (изменение процента выполнения привычки по дням/неделям).
- Круговая диаграмма распределения выполнения по категориям за выбранный месяц.

6. Напоминания и уведомления
- Настраиваемые уведомления (через стандартный Windows Toast или просто диалог при запуске приложения) о том, что пора выполнить привычку.
- Уведомление, если привычка не выполнена в текущий день, за 2 часа до конца дня (опционально).
- Поздравление с достижением нового рекорда серии (стрика).



7. Экспорт данных
- Экспорт отчёта о прогрессе по выбранной привычке (или всем привычкам) в форматы CSV или PDF (таблица дат, статус выполнения, количественное значение).

8. Персонализация интерфейса
- Возможность переключать тему оформления (светлая / тёмная).
- Настройка отображения виджетов (например, показывать только самые проблемные привычки или наоборот лучшие).

Нефункциональные требования

- Производительность: загрузка списка привычек за месяц не должна превышать 1 секунду при 100+ привычках.
- Масштабируемость и поддерживаемость кода: использование MVVM-паттерна, разделение на уровни (Presentation, Business Logic, Data Access).
- Локализация: интерфейс должен быть выполнен на русском языке. Английская версия – дополнительное задание (по желанию).
- Надёжность: приложение не должно терять данные при некорректном завершении (транзакционная запись в БД).

Итоговый результат и сроки выполнения

Итоговым результатом выполнения данного технического задания является готовое полноценное десктопное приложение «Habit Tracker», собранное в «.exe» файл (с возможностью запуска без установки .NET SDK, если используется self-contained publish).  
К проекту прилагается:
- исходный код решения (Visual Studio Solution);
- скрипт создания базы данных MS SQL (схема, начальные категории);
- краткая инструкция пользователя (в формате PDF или встроенная справка).
- исходный код, выложенный на GitHub в закрытый репозиторий с подробным README.md файлом.
