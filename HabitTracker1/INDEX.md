## 🏗️ Архитектура проекта

### Иерархия слоев
```
┌─────────────────────────────────────┐
│  Presentation Layer (WPF Views)     │  ← Интерфейс пользователя
├─────────────────────────────────────┤
│  View Models + Commands             │  ← MVVM логика
├─────────────────────────────────────┤
│  Services (Business Logic)          │  ← Бизнес-логика
├─────────────────────────────────────┤
│  Data Access Layer (DbConnection)   │  ← Доступ к данным
├─────────────────────────────────────┤
│  SQL Server Database                │  ← Хранилище данных
└─────────────────────────────────────┘
```

### Компоненты по папкам
```
Models/              → Модели данных (User, Habit, Category, Log)
Services/            → Бизнес-логика (Auth, Habit, Category, Stats)
ViewModels/          → MVVM логика (4 ViewModel класса)
Views/               → WPF интерфейс (10 компонентов)
Data/                → Доступ к БД (DatabaseConnection)
Database/            → SQL скрипты и документация
```

## 📖 Быстрая справка

### Основные понятия

**User** - Пользователь приложения
- Имя пользователя (уникальное)
- Пароль (в виде SHA256 хеша)
- Email (опционально)
- Дата создания и последнего входа

**Habit** - Привычка, которую нужно выполнять
- Название и описание
- Категория (опционально)
- Частота выполнения (ежедневно, по будням и т.д.)
- Целевое значение и единица измерения
- Время напоминания

**Category** - Группа привычек
- Название
- Принадлежность пользователю
- Может содержать несколько привычек

**HabitLog** - Запись о выполнении привычки
- Дата выполнения
- Статус (выполнено/не выполнено)
- Количественное значение (опционально)
- Заметки

### Частоты выполнения

| Тип | Описание | Пример |
|-----|---------|--------|
| Daily | Ежедневно | Каждый день |
| Weekdays | По будням | Пн-Пт |
| Weekly | Еженедельно | Один раз в неделю |
| EveryNDays | Каждые N дней | Каждые 3 дня |
| SpecificDays | Определенные дни | Вт, Чт, Сб |

## ❓ Часто задаваемые вопросы

### В: Как изменить подключение к БД?
**О:** Отредактируйте `Data/DatabaseConnection.cs` строка 11

### В: Как добавить новую привычку?
**О:** На странице "Мои привычки" нажмите "+ Добавить привычку"

### В: Где хранятся пароли?
**О:** В базе данных в виде SHA256 хешей (нельзя восстановить)

### В: Как экспортировать данные?
**О:** Пока не реализовано (есть в планах развития)

### В: Можно ли использовать без SQL Server?
**О:** Нет, требуется SQL Server для хранения данных

### В: Какой .NET требуется?
**О:** .NET Framework 4.7.2 или выше
